观察日期：2026-11-14。来源：[dapanyuntu.com](https://dapanyuntu.com/)。

## 布局与层级

1440 × 1000 视口下，原站左侧控制栏为 162px，Canvas 位于 x=162、y=0，尺寸为 1278 × 959 CSS px。底部约 41px 放置色尺和视图工具。Canvas 占视口约 85%，首屏没有另一个高大的品牌栏、标题区或环绕图表的卡片留白。

这让用户先看到市场本身。市场入口、筛选、涨跌家数和成交额集中在侧边；低频的主题、分享、全屏等工具退到底边。

云图本身使用三层结构：一级行业 → 二级行业 → 个股。一级行业比个股有更强的分隔，二级行业提供局部语义；两层标题条本身也表达当前分组的涨跌状态，而不是把每个行业做成相同的灰色标签。个股之间约 1 CSS px 的细槽，行业之间有更明显的中性分隔。

## 标签的实际做法

从运行中的 Canvas 文本调用观察到：

- 大权重个股使用约 20–30px 的较大文字，名称、涨跌幅居中，足够大的单元还能显示价格。
- 中等单元多为左上排布，名称与涨跌幅形成两行；小单元只显示可容纳的名称前缀，最小单元不强制显示完整文字。
- 字号随单元大小调整；本次抓取见到约 6–30px 的图内字号。极小字号是原站的密度选择，不应直接成为本产品的可读性标准。
- 字体栈以 Avenir Next Condensed / DIN Condensed 为首，随后为苹方、微软雅黑、Arial 和 sans-serif 回退。

公开绘制函数可确认：先测量字符串宽度，再查找可容纳的字符前缀；每个单元建立独立裁剪区域后绘制。没有利用 `fillText` 的 `maxWidth` 参数把整段中文横向压扁。重要的是字形、留白和裁剪的正确性，不是照抄某个字号。

## 实际交互

本次实际执行了主题切换、股票悬停、一级行业标题点击。页面可见操作说明还明确提供滚轮缩放、缩放后拖拽、全屏、截图与检视器固定 / 停靠等能力；这些说明不代表本轮逐个操作验收了全部能力。

行业聚焦是最重要的渐进披露：全图先看结构，进入行业后再看清局部标的。它比在全市场状态下把所有股票名称塞进小矩形更适合找行业强弱与权重股。

## 从用户任务推导本轮设计

短线看盘的首要任务是快速辨认整体强弱、行业差异和异常个股。由此得到以下改造要求：

1. **先给市场足够面积。** 增加云图有效高度，压缩重复标题和外围装饰；保留观潮看盘原有的情绪与复盘模块，但让它们服务主图。
2. **先修几何，再修装饰。** 分块算法应保持权重与较合理的长宽比，避免行业退化成一条条横带；面积语义不能为视觉好看而失真。
3. **重建行业结构。** 利用原样本的 `subBoardName` 组织二级行业，不另造分类或虚构数据。
4. **标签必须有真实显示预算。** 测量文字后决定两行、单行、前缀或不显示；不横向挤压中文，不把全部小块都变成文字纹理。
5. **提供进入和返回。** 一级行业聚焦应有明确返回全图入口，聚焦后重新布局，以更大可读单元展示该行业。
6. **细节按需出现。** 股票价格、涨停原因、竞价等内容留给检视面板，不抢占所有矩形的有限空间。
7. **保留当前产品承诺。** 观潮看盘继续使用浅色框架，以及已确定的红涨、绿跌、黑平盘三色；原站的连续色阶、灰平盘和默认深色不直接覆盖这些决定。

## 借鉴范围与来源边界

本轮借鉴主图优先的空间分配、三级分组、按面积决定标签、独立裁剪、行业聚焦与清楚的返回路径。原站品牌、营销入口、图像资产、完整业务代码和专有数据接口不搬入产品。
