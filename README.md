## 问题记录（留存）

### 2026-11-14 改代码"怎么还是这样"——根因链（已全部修复并固化）

1. **浏览器缓存旧 app.js**：服务器原发 `Cache-Control: no-cache` 且无校验头，浏览器仍可能复用旧缓存。
   → 已改 **`no-store`**，并在 index.html 中给 `app.js` 注入版本参数 `?v=<mtime>`（server.js 内 fs.watch 自动随文件保存刷新版本号）。
2. **后台页签 rAF 暂停**：canvas 只剩加载时的那一帧，截图管道（合成器最后呈现帧）可能拿到旧画面——与 getImageData 读到的后备存储不一致。
   → 已改为 applyFilter/layoutAll 中**同步 drawFrame 一次** + 单循环 rAF；截图存疑时用 `canvas.toDataURL()` 导出后备存储真值比对。
3. **node 字符串补丁括号失衡**：多段补丁时 if{ 嵌套漏 `}` 导致整段 JS 不解析、页面静默白屏。
   → 规程：补丁后必须 `node --check` 校验，再 reload + 像素断言（金框像素数 / 红绿语义抽检）。
