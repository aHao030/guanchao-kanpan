# 观潮看盘（panjian-hub）

合并「大盘云图 dapanyuntu.com」+「盘见 fupanla.top」数据的 A 股市场结构与涨停复盘界面（演示原型，静态样本数据）。

## 启动

```
node server.js     # http://127.0.0.1:8791
```

运行页面不需要安装依赖。需要更换预览端口时，在 PowerShell 中运行：

```powershell
$env:PORT = '8792'
node server.js
```

## 界面与可靠性优化（2026-11-14）

- 保留顶部市场概览、左侧树图与右侧详情、五格情绪、时间轴与情绪走势；静态样本与数据口径不变。
- 白色工作面、冷灰底色与钴蓝选中态；保留涨红 `#ef4444`、跌绿 `#22c55e`、平盘黑 `#111418`。字体使用本地系统字库，页面无需连接外部字体服务。
- 手机采用纵向布局，完整保留情绪五项与走势；支持键盘切换标的池及打开列表中的股票。
- 修复首板筛选、涨幅排序、大市值顺序、选中描边刷新，以及隐藏遮罩覆盖树图的问题。
- 缓存静态行业排序与显示配额，合并窗口变化的重复绘制；静态画面不再持续刷新。
- 服务支持独立端口；无效 URL 不再导致进程退出，限制读取范围并正确处理 GET / HEAD。

技能来源与应用方式见 [docs/WORKFLOW.md](docs/WORKFLOW.md)，设计规范见 [DESIGN.md](DESIGN.md)。

## 验证

HTTP 测试使用 Node.js 自带的测试工具；页面行为测试需要 Playwright 与本机 Google Chrome：

```powershell
npm ci
npm test
```

也可分别运行 `npm run test:server` 或 `npm run test:ui`。测试覆盖筛选、排序、搜索、详情返回、三色像素、键盘操作、窗口缩放后的时间轴交互和真实 HTTP 行为。`playwright` 仅用于开发测试，启动服务仍为零依赖。

## 问题记录（留存）

### 2026-11-14 改代码"怎么还是这样"——根因链（已全部修复并固化）

1. **浏览器缓存旧 app.js**：服务器原发 `Cache-Control: no-cache` 且无校验头，浏览器仍可能复用旧缓存。
   → 已改 **`no-store`**，并在 index.html 中给 `app.js` 注入版本参数 `?v=<mtime>`（server.js 内 fs.watch 自动随文件保存刷新版本号）。
2. **后台页签 rAF 暂停**：canvas 只剩加载时的那一帧，截图管道（合成器最后呈现帧）可能拿到旧画面——与 getImageData 读到的后备存储不一致。
   → 已改为 applyFilter/layoutAll 中**同步 drawFrame 一次** + 单循环 rAF；截图存疑时用 `canvas.toDataURL()` 导出后备存储真值比对。
3. **node 字符串补丁括号失衡**：多段补丁时 if{ 嵌套漏 `}` 导致整段 JS 不解析、页面静默白屏。
   → 规程：补丁后必须 `node --check` 校验，再 reload + 像素断言（金框像素数 / 红绿语义抽检）。

### 配色定版（用户指定）

- 树图三色：**涨红 #ef4444 / 跌绿 #22c55e / 不涨不跌(±0.1%) 黑 #111418**，绿块墨字、红/黑块白字。
- 迭代史：大盘云图连续渐变（浅底显淡）→ RdYlGn 11 阶分档（用户仍嫌花）→ 三色方案（定版）。色值出处均为大盘云图前端包同款红绿。
- 界面框架浅色（用户否决整体暗色）；画布内允许黑色平盘块。
